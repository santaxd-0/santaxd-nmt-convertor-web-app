# 🧾 NMT Convertor Web App

A simple and modern web app that allows users to **create custom forms with tasks**, preview them **live as a PDF**, and **download the result** in either `.pdf` or `.tex` format.

Built with focus on simplicity, clean design, and smooth user experience.

---

## 🚀 Features
- ✍️ Create and customize your own forms  
- 👀 Live preview of the generated PDF  
- 💾 Download as `.pdf` or `.tex` file  
- 🎨 Modern UI with **Tailwind CSS** + **shadcn/ui** components  
- ⚙️ Backend integration (in progress)

---

## 🧠 Tech Stack
- **Next.js** – frontend framework  
- **TypeScript** – type-safe code  
- **Tailwind CSS** – styling  
- **shadcn/ui** – clean and reusable components
